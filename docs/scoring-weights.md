# 점수 가중치

종합 점수는 모델이 아니라 `@sniff/core`의 `computeVerdict`(`packages/core/src/scoring.ts`)가 결정적으로 계산합니다.

## 가중치

| 항목 | 가중치 | 산출 주체 |
| --- | --- | --- |
| 리뷰 신뢰도 (`reviews`) | 30% | 모델 |
| 광고 정직도 (`adHonesty`) | 25% | 모델 |
| 성분 안전성 (`ingredients`) | 15% | 모델 |
| 가격 대비 가치 (`value`) | 15% | 모델 |
| 근거 출처 신뢰도 (`sourceReliability`) | 15% | **코드** |

## 변경 이력

- 기존: 리뷰 35 · 광고 25 · 성분 20 · 가성비 20
- 변경: 리뷰 30 · 광고 25 · 성분 15 · 가성비 15 · **근거 출처 신뢰도 15 (신규)**
- 이유: 클리앙·디시인사이드 같은 커뮤니티까지 조사하고, 그 근거가 얼마나 다양하고 믿을 만한지를 점수에 일부 반영하기 위해 새 항목을 추가했고, 그만큼 기존 항목의 비중을 줄였습니다.

## 근거 출처 신뢰도 (`computeSourceReliability`)

모델이 각 출처에 붙인 유형(`shop_review` 쇼핑몰 리뷰 / `blog` / `community` 커뮤니티 / `official` / `news` / `other`)과 협찬·조작 의심 신호 개수로 코드에서 계산합니다.

| 요소 | 점수 |
| --- | --- |
| 기본 | +30 |
| 리뷰형 출처 유형(쇼핑몰·블로그·커뮤니티) 하나당 | +15 |
| 커뮤니티 출처가 하나라도 있음 | +15 |
| 리뷰형 출처 하나당 (최대 6개) | +3 |
| 협찬·조작 신호 하나당 (최대 4개) | −5 |

결과는 0~100으로 제한하며, 리뷰형 출처가 하나도 없으면 `null`(점수 없음)입니다.

## 계산 규칙

- `null`인 항목(근거 부족, 해당 없음)은 제외하고 남은 가중치로 다시 정규화합니다.
- 가용 가중치 합이 50% 미만이면 판정을 보류합니다(`insufficient_data`).
- 허위 광고 또는 경고 수준 성분이 있으면 종합 점수를 60점 이하로 제한합니다.
- 등급: 75점 이상 추천, 55점 이상 신중히 검토, 그 미만 비추천.
